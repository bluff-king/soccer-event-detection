Id trận dùng '\' trên Windows làm mọi phép so khớp trả về rỗng

2026-10-13 · soccer-event-detection · trang sinh bởi scripts/build_lessons.py từ dữ liệu của lần chạy thật

Triệu chứng

Trên Windows: nguồn asr_views chỉ lấy được một biến thể Whisper (whisper_v1_en); manifest báo kaggle_games_removed_overlap_valid_test: 0 trong khi README vòng 1 (Colab, Linux) ghi 89.

Sai và đúng

id trận do list_games() trả trên Windows (lỗi):  england_epl\2014-2015\2015-02-21 - 18-00 Chelsea 1 - 1 Burnley
khoá trong SN-echoes-lang.csv:                   england_epl/2014-2015/2015-02-21 - 18-00 Chelsea 1 - 1 Burnley/1
gói SoccerNet getListGames() cũng trả:           england_epl\2014-2015\2015-02-21 - 18-00 Chelsea 1 - 1 Burnley
Nguyên nhân gốc: id trận được tạo bằng str(Path) (và os.path.join trong gói SoccerNet) nên dùng \ trên Windows, rồi được so như chuỗi với dữ liệu viết bằng /: mọi phép so khớp âm thầm trả về "không tìm thấy" thay vì báo lỗi.

Nguồn: tính lại trong script này trên đúng dữ liệu đã tải — 550 trận Echoes, SN-echoes-lang.csv, football-events/ginf.csv, danh sách trận valid/test của data/processed/manifest.json. Cột tím là kết quả khi id dùng \.

Hậu quả nếu không phát hiện

  • 89 trận Kaggle trùng với valid/test lọt vào tập train (rò rỉ) khi chạy trên Windows.
  • Biến thể ASR "khuyến nghị theo ngôn ngữ" không được dùng: mọi hiệp rơi về mặc định v2.
  • Không có lỗi nào được báo — chỉ số liệu hơi lệch.

Cách phát hiện

So số trong manifest với số đã ghi trong README (89 → 0), và một nguồn dữ liệu mới cho ra ít biến thể hơn số thư mục có trên đĩa.

Bài học

  • Id dùng để so khớp chuỗi phải chuẩn hoá (as_posix()), không dùng str(Path); chuẩn hoá cả dữ liệu từ thư viện ngoài.
  • Phép lọc chống rò rỉ phải có số kỳ vọng để đối chiếu (test test_asr_views.py kiểm id dùng /).
